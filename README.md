## Overview

FabFilter Volcano 3 is an expressive multiband filter plugin combining up to four modulated filter bands with feedback, stereo spreading, and extensive modulation for creative sound design.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **FabFilter Volcano 3** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Four Filters** | Up to four independently movable filter bands with multiple types |
| **Modulation** | LFO, MIDI, and audio-rate modulation per filter band |
| **Feedback** | Global feedback path creates resonant and comb filter effects |
| **Stereo Spread** | Per-band stereo pan for dynamic spatial filtering effects |
